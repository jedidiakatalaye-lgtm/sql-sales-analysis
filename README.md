# SQL Sales Analysis

Six SQL queries answering real business questions on an e-commerce database: revenue growth, best products, customer value, retention, and returns.

> **Data note:** the database is **synthetic** (generated by `build_db.py` with a fixed seed, so anyone can reproduce it). The point of this project is the SQL, not the business conclusions.

## Skills shown
CTEs, multi-table JOINs, window functions (`LAG`, `ROW_NUMBER`, `NTILE`, running `SUM OVER`), conditional aggregation, cohort analysis.

## Run it (no database install needed, uses SQLite)
```bash
python build_db.py       # creates sales.db
python run_queries.py    # runs all queries, saves results/*.csv
```

## Schema
`customers` -> `orders` -> `order_items` -> `products` (see `sql/schema.sql`).
Revenue = quantity x price x (1 - discount), completed orders only.

## Queries and what they answer
| File | Question |
|---|---|
| `01_monthly_revenue_growth` | How is revenue changing month over month? |
| `02_top3_products_per_category` | Which products drive each category? |
| `03_customer_value_segments` | How concentrated is revenue among customers? |
| `04_cohort_retention` | Do customers come back after their first order? |
| `05_running_revenue_by_country` | How does cumulative revenue grow per market? |
| `06_cancel_return_rate_by_category` | Which categories have the most cancellations/returns? |

## Findings (on the synthetic data)
- **Electronics is ~47% of revenue** (Home 21%, Fitness 14%, Beauty 12%, Books 7%). Revenue is concentrated in one category.
- **The top 25% of customers generate ~56% of revenue**; the bottom 25% generate ~5%. Retention of high-value customers matters most.
- **November and December roughly double monthly revenue** versus October (about $31k and $39k vs $17k), a clear seasonal peak to plan stock and campaigns around.
- **Cancellations run 7-8% and returns 5-6% in every category**; Beauty is slightly highest on both, so no category is an outlier.
- **Cohort retention is weak**: for example, of 18 customers who first ordered in Feb 2025, 9 ordered again the next month and 5 by month three (see `results/04_cohort_retention.csv`).
